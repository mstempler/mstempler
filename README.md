## How to read the evidence

Recorded CI means a successful run was observed, not independently reproduced. Source inspection means selected implementation was reviewed, not certified. Structural evidence means filenames and dependencies were inspected. Proposed controls and business metrics are not achieved results. The underlying review is not independent; private evidence is not publicly reproducible.
